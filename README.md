그림을 직접 그리는 범용 그래픽 편집기의 기능을 모두 담는 대신, AI 만화 연재에 자주 쓰는 작업과 빠른 반복 편집에 초점을 맞춥니다. 가져온 원본 이미지는 수정하지 않으며 프로젝트 안에 함께 보관합니다.

## 주요 기능

- 패널, 이미지, 말풍선, 텍스트 기반의 페이지 편집
- 이미지 드래그 앤 드롭 가져오기 및 캔버스 즉시 배치
- 패널 내부 요소 크롭, 패널 자유 변형, 격자·직선 분할
- 이미지 이동, 크기 조절, 회전, 자르기, 좌우반전, 복제
- 다중 선택, 사각 선택, 레이어 트리 및 요소 잠금
- 타원, 손그림, 구름, 외침, 가시, 사각형, 다각형 말풍선
- 말풍선 꼬리 편집 및 가까운 말풍선 자동 병합
- 채우기·테두리 그래디언트와 이펙트
- 페이지·이미지·글로벌 에셋 썸네일 관리
- PNG/JPEG 페이지 내보내기
- 프로그램 폴더 안에서 동작하는 포터블 저장 방식

## 설치 및 실행

1. GitHub의 **Releases**에서 최신 Windows 배포 파일을 받습니다.
2. ZIP 파일을 쓰기 가능한 폴더에 압축 해제합니다.
3. `Komika.exe`를 실행합니다.

설치 프로그램은 필요하지 않습니다. 코미카는 실행 파일이 있는 폴더에 `data/`와 `projects/`를 만들므로 `Program Files`처럼 쓰기가 제한된 위치는 피하는 편이 좋습니다.

업데이트할 때는 실행 파일만 교체하면 됩니다. 개인 프로젝트가 있는 `projects/`와 설정·글로벌 에셋이 있는 `data/`는 그대로 유지하십시오.

## 빠른 시작

1. 시작 화면에서 **프로젝트 생성**을 선택합니다.
2. 프로젝트 이름, 캔버스 크기, 배경색과 저장 위치를 지정합니다.
3. 이미지 파일을 프로그램 창 또는 **이미지** 독으로 드래그합니다.
4. 이미지를 캔버스로 드래그해 배치합니다.
5. 상단의 **패널**, **말풍선**, **텍스트** 도구로 페이지를 구성합니다.
6. 요소를 선택하고 프로퍼티 독에서 모양과 스타일을 조정합니다.
7. 상단의 **내보내기**에서 현재 페이지 또는 전체 페이지를 PNG/JPEG로 저장합니다.

프로그램 안에서 `F1`을 누르면 전체 단축키와 조작법을 확인할 수 있습니다.

## 편집 화면

편집 화면은 중앙 캔버스와 이동 가능한 독으로 구성됩니다.

| 독 | 역할 |
| --- | --- |
| 페이지 | 페이지 추가·삭제·선택·순서 변경과 썸네일 표시 |
| 트리 | 요소의 레이어·부모 관계 확인, 선택, 잠금, 이펙트 열기 |
| 프로젝트 | 캔버스 크기, 페이지 배경, 패널 간격, 말풍선 연결과 썸네일 설정 |
| 프로퍼티 | 선택 요소의 위치, 크기, 스타일과 텍스트 설정 |
| 이미지 | 현재 프로젝트에 포함된 원본 이미지 관리 |
| 에셋 | 모든 프로젝트가 공유하는 말풍선·텍스트·레이아웃 프리셋 |

독 탭을 드래그하면 위치를 바꿀 수 있고 독 사이 경계를 드래그하면 크기를 조절할 수 있습니다. **독 초기화**로 기본 배치로 돌아갈 수 있습니다.

## 패널과 요소

패널은 내부 이미지·말풍선·텍스트의 크롭 영역으로 동작합니다. 요소를 패널 위로 드래그하는 동안 `Shift`를 누르면 패널 안에 넣거나 밖으로 꺼낼 수 있습니다. 패널을 이동하거나 회전하면 내부 요소도 함께 움직입니다.

패널의 **모양 변형** 모드에서는 꼭짓점을 드래그할 수 있고 변을 더블클릭해 꼭짓점을 추가할 수 있습니다. 뾰족하거나 오목한 패널도 만들 수 있으며, 자기 자신과 교차하는 윤곽은 허용하지 않습니다.

프로젝트 독의 가로·세로 패널 간격은 격자 자르기와 자유 자르기에 사용됩니다. 대각선 절단에는 두 간격을 방향에 따라 보간해 적용합니다.

## 말풍선과 텍스트

말풍선은 폴리곤으로 렌더링하며 모양, Seed, 강도, 채우기, 테두리와 그래디언트를 설정할 수 있습니다. 꼬리를 켜면 캔버스의 꼭짓점을 직접 움직이고 두께와 휘어짐을 조절할 수 있습니다.

자동 병합을 켠 말풍선은 서로 겹치거나 가까워지면 하나의 형태처럼 렌더링됩니다. 객체와 텍스트는 각각 독립적으로 유지되므로 배치하면서 결과를 바로 확인할 수 있습니다.

텍스트와 말풍선을 더블클릭하면 캔버스에서 내용을 수정합니다. 폰트, 크기, 정렬, 자간, 행간, 세로쓰기, 굵게, 기울임, 외곽선을 지원합니다. 프로젝트에는 시스템 폰트의 이름만 저장되므로 다른 PC에 같은 폰트가 없으면 대체 폰트로 표시될 수 있습니다.

## 이펙트

요소를 선택하고 `E`를 누르거나 트리 독의 Fx 버튼을 누르면 이펙트 창이 열립니다.

- 일반: 색 조절, 블러, 비네트, 디졸브, 하프톤, 집중선, 배경 패턴, 필름 그레인
- 말풍선 테두리: 가시, 털선, 분무, 겹선, 점선, 파선, 붓선, 빛 번짐
- 패널 배경: 물결 등고선, 해칭, 우울선, 도트, 소용돌이, 교차 집중선, 반짝임, 잎사귀

이펙트는 원본 이미지 데이터를 변경하지 않습니다. 패널의 일반 이펙트는 패널과 내부 요소를 합친 결과에 적용되고 패널 배경 이펙트는 배경에만 적용됩니다. 프로젝트 파일은 코미카에 내장된 이펙트 종류와 검증된 파라미터만 저장하며 외부 셰이더나 스크립트를 실행하지 않습니다.

## 프로젝트와 이미지 저장 방식

프로젝트는 `.komika` 확장자의 UTF-8 JSON 문서입니다. 페이지, 요소, 편집 상태와 가져온 이미지의 원본 바이트를 함께 저장합니다.

- 이미지 독은 원본 파일 경로를 참조하지 않습니다.
- 원본 파일을 수정하거나 이동해도 프로젝트에 가져온 이미지는 바뀌지 않습니다.
- 이미지가 Base64로 포함되므로 프로젝트 파일은 원본 이미지 합계보다 커질 수 있습니다.
- 저장 시 기존 문서는 `.bak`으로 백업하고 새 내용은 임시 파일을 거쳐 교체합니다.
- 스키마 버전 1~5 프로젝트를 읽을 수 있습니다.

자동 저장은 변경 사항이 있을 때 3분 간격으로 동작합니다. 드래그, 텍스트 입력, 내보내기 또는 대화상자 작업 중이라면 해당 작업이 끝난 뒤 저장합니다.

## 글로벌 에셋과 공유

에셋 독에는 프로젝트와 별개로 사용하는 말풍선·텍스트 프리셋과 페이지 패널 레이아웃을 저장할 수 있습니다. 에셋은 썸네일을 캔버스로 드래그해 사용합니다.

에셋 독의 **내보내기**에서 선택 항목 또는 전체 라이브러리를 `.komika-assets` 파일로 만들 수 있습니다. 다른 사용자는 **가져오기**로 등록할 수 있습니다. 에셋 묶음에는 요소 설정과 이펙트가 포함되며 프로젝트 이미지와 시스템 폰트 파일은 포함되지 않습니다.

## 포터블 데이터 구조

배포본은 다음 구조로 동작합니다.

```text
Komika/
├─ Komika.exe
├─ data/
│  ├─ global_assets.json
│  ├─ recent_projects.json
│  └─ font_favorites.cfg
└─ projects/
   └─ 작품.komika
```

| 경로 | 내용 |
| --- | --- |
| `data/global_assets.json` | 개인 글로벌 에셋과 기본 에셋 숨김·이름 설정 |
| `data/recent_projects.json` | 최근 프로젝트 목록 |
| `data/font_favorites.cfg` | 폰트 즐겨찾기 |
| `projects/` | 새 프로젝트의 기본 저장 위치 |

프로그램 폴더 전체를 복사하면 내부에 저장한 프로젝트와 설정도 함께 이동합니다. 프로그램 폴더 밖에 저장한 프로젝트는 해당 `.komika` 파일을 별도로 옮겨야 합니다.
